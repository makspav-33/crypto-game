2. ПОКРОКОВИЙ ПЛАН РОЗРОБКИ

--------------------------------------------------------------------------------



Етап 0: Авторизація та Реєстрація системи (Перед початком гри)

-------------------------------------------------------------

- Backend (Flask):

  * Створення БД SQLite з таблицею Users (id, username, password_hash, balance).

  * Ендпоінт POST /api/auth/register: приймає логін/пароль, хешує пароль 

    через SHA256 (hashlib.sha256) та зберігає в БД.

  * Ендпоінт POST /api/auth/login: перевіряє SHA256-хеш пароля, генерує JWT-токен 

    (Header, Payload: user_id, exp, role; Signature з секретом FirstnameLastname).

  * Декоратор @token_required для захисту API-маршрутів через Bearer Token.

- Frontend (React):

  * Інтерфейс авторизації у стилі хакерської ОС "HackNet OS v1.0".

  * Збереження JWT у localStorage та налаштування автоматичної підстави 

    заголовка Authorization: Bearer <token> для запитів.



Етап 1: Дашборд (DarkWeb Marketplace)

--------------------------------------

- Frontend (React):

  * Головний екран із 4 картками контрактів (Лабораторні 1-4).

  * Індикатор прогресу гравця (баланс, рейтинги, виконані завдання).



Етап 2: Реалізація ігрових модулів

-----------------------------------



[Контракт #1] Частотний аналіз та застарілі шифри (Лабораторна 1)

- Опис: Злам перехопленого листування конкурентів.

- React UI:

  * Текстове поле з зашифрованим текстом (Цезар / Перестановка).

  * Гістограма частоти літер у тексті (Chart.js / Recharts).

  * Накладання еталонного графіка частоти літер мови (UA/EN).

  * Slider/Поле для підбору ключа K або ключового слова з дешифруванням наочно.

- Flask API:

  * Ендпоінт POST /api/lab1/verify для перевірки розшифрованого тексту.



[Контракт #2] Атака на JWT чужого сервера (Лабораторна 2)

- Опис: Підвищення привілеїв у корпоративній системі.

- React UI:

  * JWT Inspector: поділ токена на Header, Payload, Signature.

  * Exploit Console: зміна в Payload значення "role": "user" на "admin", 

    підпис токена секретом замовника (FirstnameLastname).

- Flask API:

  * Ендпоінт POST /api/lab2/admin-vault перевіряє підпис, термін exp 

    та наявність привілеїв admin.



[Контракт #3] S-DES Feistel Inspector (Лабораторна 3)

- Опис: Розшифровка 8-бітного зашифрованого блоку.

- React UI:

  * Введення 10-бітного ключа та 8-бітного шифротексту.

  * Покрокова візуалізація Feistel-мережі (генерація K1/K2 через P10/P8, IP, 

    раунди Fk з S-блоками S0/S1, перемикач SW, обернена IP^-1).

- Flask API:

  * Ендпоінт POST /api/lab3/verify-sdes валідує проміжні та підсумкові обчислення.



[Контракт #4] Diffie-Hellman & MITM Interceptor (Лабораторна 4)

- Опис: Перехоплення каналу зв'язку Аліси та Боба.

- React UI:

  * Візуалізація обміну ключами (p, g, a, b, A, B).

  * MITM Interceptor: режим перехоплення, підміна публічних ключів A2 і B1, 

    вирахування ключів K1 та K2.

- Flask API:

  * Ендпоінт POST /api/lab4/mitm-simulate перевіряє обчислені значення K1/K2.
